This repository contains the data and code relevant to the manuscript titled CO2 upgrading to single cell protein: a comparative assessment of emerging pathways, submitted to Green Chemistry.

Structure Folders:

Droplet Tower Modeling: Modeling files used to predict mass transfer of CO2, H2, and O2 into the droplet tower contactors that pre-saturate the liquid feed to the gas fermentation bioreactor. DropletTowerModel_CO2Tower.m, DropletTowerModel_H2Tower.m, and DropletTowerModel_O2Tower.m are the per-gas models built from DropletTowerModel_Template.m; DropletDiameterData.csv is the droplet size distribution extracted from droplet images and used to size the towers; SCP Growth integrated with BGAL Model.xlsx couples the tower outputs to the SCP growth model to determine required partial pressure in CO2/O2 joint gas tower. PD_gqmom_0_1.m was shared by Alberto Passalacqua and should be cited: Fox, R. O., Laurent, F., & Passalacqua, A. (2023). The generalized quadrature method of moments. Journal of Aerosol Science, 167, 106096. https://doi.org/10.1016/j.jaerosci.2022.106096.

Bioprocess System Modeling: Python/BioSTEAM codebase used to build, simulate, and techno-economically evaluate the four SCP production routes (fructose, acetate, formate, and gas fermentation) using Cupriavidus necator as the host organism. Includes the full TEA and LCA-export pipeline (run_models.py, sensitivity_analysis.py, additional_analyses.py), the shared modeling library (common/, models/, perfusion_bioreactor/), and documentation of the governing equations, parameter sources, and route comparisons (docs/). See its own README.md for a full file-by-file reference.

BioSTEAM Outputs: Copy of the outputs/ directory generated by Bioprocess System Modeling/run_models.py — per-route TEA results workbooks, unit details, process flow diagrams (PFDs), one-at-a-time sensitivity analysis results and tornado charts, cost breakdown, scale curve, cross-route comparison, and 2D sensitivity heatmap results.

LCA Exports: Copy of the lca/ directory generated by Bioprocess System Modeling/run_models.py — per-route life cycle inventory (LCI) workbooks (Capital Goods and Operational Flows) formatted for import into openLCA, plus stream_balance_check.py, a diagnostic script that verifies the inventory covers every stream in the simulated system. See its own README.md for full sheet structure and unit conventions.

OpenLCAFiles.zip: openLCA project export containing the foreground and background LCA model built from the LCA Exports inventories.

OpenLCA_SAResults: openLCA sensitivity analysis results, one workbook per route per cost/utility category (Capital Goods, Electricity Demand, HX Utilities, Nutrients, Steam, Substrate Intensity), used to build the LCA tornado plots.

LCAResults: Final LCA results and figure-generation scripts. SCPLCAResults_KPIs.xlsx and SCPLCA_TornadoPlotResults.xlsx contain the computed KPI and tornado-plot values reported in the manuscript; lca_kpi.py and lca_tornado.py generate the corresponding figures.
